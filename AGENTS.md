## What this is

Firmware for an **ESP32-WROOM-32** (4 MB flash, `esp32dev` board in
PlatformIO) built with **PlatformIO** using the **ESP-IDF** framework (not
Arduino). Entry point is `app_main()` in `src/main.c`. It currently runs a
Wi-Fi + OTA demo: press **BOOT** to download a new image from the LAN.

| Path | Purpose |

| `sdkconfig.defaults` | Project-wide overrides used when sdkconfig is generated (4 MB flash, custom table, rollback, OTA-over-HTTP). |
| `.pio/` | Build output, toolchain cache. **Generated — never edit or commit.** |

## Build / flash / monitor

```bash
pio run                       # compile
pio run -t upload             # compile + flash (auto-detects serial port)
pio run -t upload -t monitor  # flash then open serial monitor
pio device monitor -b 115200  # serial monitor only
pio run -t erase              # erase flash
pio run -t clean              # remove build artifacts
```

Upload port: PlatformIO auto-detects; override with
`pio run -t upload --upload-port /dev/ttyUSB0` (Linux) or `/dev/ttyACM0`.
`pio device list` shows what the machine can see.

If `pio` is not on `PATH`, use the PlatformIO venv directly:
`~/.platformio/penv/bin/pio`.

## OTA updates over Wi-Fi

`partitions.csv` creates two app slots plus `otadata`, so a new image is written
to the inactive slot and selected on the next boot:

| Partition | Offset | Size |
| --- | --- | --- |
| `nvs` | `0x9000` | 24 K |
| `otadata` | `0xf000` | 8 K |
| `phy_init` | `0x11000` | 4 K |
| `ota_0` (app) | `0x20000` | 1700 K |
| `ota_1` (app) | `0x1d0000` | 1700 K |

Workflow:

```bash
# 1. First time, and after any partition-table change: USB flash
pio run -t upload

# 2. Serve the freshly built image on the LAN
cd .pio/build/esp32dev && python3 -m http.server 8000

# 3. On the board, press BOOT (GPIO0) while the app is running
# 4. Watch progress
pio device monitor -b 115200
```

Configure `WIFI_SSID`, `WIFI_PASSWORD` and `OTA_URL` at the top of
`src/main.c`. `OTA_URL` must be the **computer's LAN IP**, e.g.
`http://192.168.1.100:8000/firmware.bin` — not `localhost`, which on the ESP32
means the ESP32 itself. Wi-Fi must be 2.4 GHz.

Behaviour notes:

- OTA alternates between `ota_0` and `ota_1`; `esp_ota_get_running_partition()`
  reports which one booted.
- Rollback is enabled (`CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y`). A new image
  must call `esp_ota_mark_app_valid_cancel_rollback()` (done at the top of
  `app_main`) or the bootloader reverts on the next reset.
- `CONFIG_ESP_HTTPS_OTA_ALLOW_HTTP=y` allows plain `http://` for local testing;
  use HTTPS and remove it for anything real.
- The image must fit the 1700 K slot — check the `Flash:` line from `pio run`.
- OTA cannot change the partition table; table changes require USB.
- `pio run -t erase` wipes NVS (Wi-Fi/rollback state) but does not relayout flash.

## Conventions

- Language: C (C11 via ESP-IDF). Keep new sources under `src/` so the glob in
  `src/CMakeLists.txt` picks them up; no manual source list to maintain.
- Logging: use `ESP_LOGx(TAG, ...)` with a `static const char *TAG`. Plain
  `printf` only for very early boot output.
- Delays: `vTaskDelay(pdMS_TO_TICKS(ms))` from FreeRTOS; never busy-wait.
- Check return values of ESP-IDF calls (`esp_err_t`) and log failures.
- Do not add Arduino code or libraries; this project is ESP-IDF only.
- Do not commit `.pio/` or `sdkconfig.esp32dev` changes unless intentionally
  changing target config (`.gitignore` covers `.pio`).

## Gotchas

- First build downloads the ESP-IDF toolchain into `~/.platformio/`; it is slow.
- Serial output is 115200 baud by default.
- If the board does not enter download mode automatically, hold **BOOT** while
  the upload starts, then release.
- A clean rebuild may be needed after changing `platformio.ini` or sdkconfig
  options: `pio run -t clean && pio run`.
- The board is an ESP32-WROOM-32 with **4 MB flash**. `sdkconfig.defaults`
  pins `CONFIG_ESPTOOLPY_FLASHSIZE_4MB=y`; keep it in sync with
  `sdkconfig.esp32dev` if you regenerate that file.
- Flash layout is now **two OTA slots** from `partitions.csv`, not
  `single_app`. Verify the built table with:
  `python3 ~/.platformio/packages/framework-espidf/components/partition_table/gen_esp32part.py .pio/build/esp32dev/partitions.bin`
- `sdkconfig.esp32dev` is generated: delete it to apply changes made to
  `sdkconfig.defaults`, then rebuild.
- Wi-Fi credentials live in `src/main.c` (`WIFI_SSID` / `WIFI_PASSWORD`) —
  replace the placeholders before testing OTA.
